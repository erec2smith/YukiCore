# Changelog

## 1.1.0

- Windows system: every panel is a window you can fold, close and reopen from the top bar.
- Page tabs under the header.
- Events: when something happens to an element, show, hide, toggle, change text or style, add classes, play an animation, scroll, go to a page, open a link, show a message or copy text.
- Hidden at start option for elements.
- Layer controls: front, back, forward, backward, X, Y, Z, size fields with arrow key stepping, keyboard nudging.
- Eight resize handles, a move grip, and a toolbar that no longer covers the element.
- Alt+click and right-click to reach elements stacked under others. Lock and hide in the editor from the Layers window.
- Zoom from 40% to 200%.
- Preview in a new browser tab with working links between pages.
- Ready-made blocks and starter templates, welcome guide, shortcuts list.
- One-file installers for Windows, macOS and Linux.

## 1.0.0

- First version: drag and drop builder, device views, export to HTML, CSS and JS.
