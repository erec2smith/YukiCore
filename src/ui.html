Welcome to YokiCore

Build a web page by clicking and dragging, then export plain HTML, CSS and JavaScript.

  1. Add elements or ready-made blocks from the Add window.
  2. Click anything on the page to style it. Hold Alt and click to pick what is underneath, or right-click to see everything under the cursor.
  3. Events let you say "when this is clicked, show that box".
  4. Preview in a new tab, then Export. Close any window you do not need and bring it back from the Windows buttons at the top.
